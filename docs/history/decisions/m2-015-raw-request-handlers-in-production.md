# Raw Request handlers in production (M2-015)

> **Current.** Now described in [raw reference](../../reference/raw.md#raw-handlers-and-binary-bodies) and [ARCHITECTURE, "Request handling"](../../ARCHITECTURE.md#request-handling).
> Changed in part since:
> - [M3-015 production](m3-015-registration-on-generic-arity-slots-in-production.md): the raw overloads and the `not B == Request` guard gave way to the generic slots, where `A == Request` is the raw kind.
> - [M3-030](m3-030-method-not-allowed-decision.md): a method mismatch on a raw route's path is 405, not 404.
> - [M3-040](m3-040-binary-request-and-response-bodies-decision.md): the rebuilt Request takes the body bytes passed beside the string arguments.
> Its pointers into documents that were split or renamed since (`docs/DX.md`, old `docs/ARCHITECTURE.md` headings) are mapped in [the list of records](../architecture-decisions.md#documents-older-records-cite).

Production implements the M2-014 slice above ("Next production slice"), and nothing more. Public surface: one overload on each method, after its typed overloads,

```mojo
def get[E: Deinitable, //, path: StaticString](
    mut self, handler: def(var Request) thin raises E -> Response
)
def post[E: Deinitable, //, path: StaticString](
    mut self, handler: def(var Request) thin raises E -> Response
)
```

so `def webhook(req: Request) -> Response` registers as `app.post["/webhook"](webhook)` (DX section 9; `tests/test_raw.mojo` registers that handler, verbatim, and checks its responses).

- **Selection:** as decided, by the Mojo 1.1.0 rule "shorter parameter list": `[E, path]` against the generic body overloads' `[B, E, R, path]` (`post`); on `get` nothing else takes a `Request`. No defaults or extra generics were added, so the M2-014 ranking proof applies unchanged and `raw_fail/equal_parameter_lists.mojo` still pins it. Production confirms it: giving the raw `post` overload three defaulted extra parameters (its list now longer) sends a raw handler to the generic body overload, where the `Request` guard rejects it (mutation below). The guard (`comptime assert not B == Request`, before `FromBody` in all four body overloads) runs only in an overload already selected, so it takes no part in selection.
- **Dispatch:** `_Route.raw`. After method and path match, `App.handle` gives a raw route `request.method`, `path`, `query` and `body` as its four raw arguments and skips the typed branch (query gathering, body argument); `_call_raw[E]` rebuilds a fresh `Request` with the public initializer (target `path`, plus `"?" + query` when the query is not empty), moves it into the handler, catches only the handler call (`_handler_error[E]`), and returns its `Response` unconverted. The caller's `Request` is borrowed and untouched (a `var req` handler that moves `req.body` out leaves it intact). Lossless for every field, as argued in M2-014.
- **Status codes:** no route match (method or path) is 404 and the handler does not run. A matched raw route generates no 400 of its own: `_query_value`, `_parse_int` and `from_body` never run, so queries a typed route rejects (`?id`, `?id=`, `?id=abc`, `?id=1&id=2`, `?{id}`) and an empty body reach the handler. The handler's `Response`, or its error's `to_error_response()`, may use any status, 400 included. Bare `raises` and a non-opted `raises T` are the fixed 500 with the error dropped unread; first registration wins across raw and typed routes in both orders, and a typed route's 400 does not fall through to a later raw one.
- **Unchanged:** `_handler_storage.mojo`, `_Erased`, `_Call[F]`, the unsafe surface and `check_unsafe.sh`, `http.mojo` (`Request`/`Response` representation), `body.mojo`, `testing.mojo` (`TestClient`), `__init__.mojo`, `adapters/flare/muntin_flare.mojo`, and the seam `App.handle(Request) -> Response`. The eight typed overloads keep their signatures, adapters and checks; each body overload gains only the guard. Every typed suite passes unchanged, and every existing fixture keeps its expected text except the two the slice names.
- **Fixtures:** `body_fail/post_raw_handler.mojo` retired (now `tests/test_raw.mojo`); `compile_fail/post_request_param.mojo` expects the guard; `storage_fail/request_param_handler.mojo` keeps its expected text (comment updated: raw handlers return `Response`). Added, production counterparts of `raw_fail`: `compile_fail/raw_post_typed_return.mojo`, `raw_post_int_and_request.mojo` and `raw_post_int_and_request_string.mojo` (with `post_request_param`, one fixture per guarded body overload), `raw_{get,post}_{path,query}_placeholder.mojo` and `raw_malformed_route.mojo` (`def()`'s messages), `storage_fail/raw_get_string_return.mojo` (the raw candidate's note on `get`), `storage_fail/raw_borrowed_function_value.mojo` and `raw_function_value_without_raises.mojo` (the closure-conversion `TODO`; an explicit `def(var Request) thin raises Never -> Response` value registers, `tests/test_raw.mojo`), `body_fail/raw_extra_parameter.mojo`. The M2-014 spike, `raw_fail` and the equal-list fixture stay as decision evidence.
- **Evidence:** `tests/test_raw.mojo` (12): the DX section 9 example; GET and POST raw routes receive the exact method, path, query and body over twelve query forms (none, `?`, duplicated, empty, non-integer, placeholder-like, `?a?b=c?`, percent/`+`/`#` text) and three bodies (empty included); borrowed and owned handlers, and the caller's `Request` unchanged; an explicit function value; no typed extraction (application `from_body` and typed handler counters 0, with a typed control that does run them); a raw handler answering 400 itself and through `ToErrorResponse`; 404 for method/path mismatches (case, trailing segment, query-looking path) without the handler; bare and non-opted raises 500 without the error text; `raises BadSignature` 401; all typed shapes and both result policies beside raw routes, including a raising typed handler and a typed `-> Response` body handler; first registration in both orders on GET and POST, a typed 400 not falling through; `TestClient` equal to `App.handle`. Loopback through Flare: raw `POST /webhook` (`raises Unsigned`, `Unsigned: ToErrorResponse` in the test module) echoes the request with a duplicated non-integer query and a body with `&`, `?` and a newline (202), answers 401 for an empty body, and 404 for `GET /webhook` and `POST /webhook/x`, each equal to `TestClient`.
- **Not in the slice:** raw route values, `String`/`ToResponse` raw results, headers, a raw target field, new methods, middleware, state, `_Erased`/`_Call` or `Request` changes. The M2-014 revisit conditions apply unchanged.
