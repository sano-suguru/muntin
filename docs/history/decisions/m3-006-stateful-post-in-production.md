Status: **production**, the `post` half of the M3-001 typed family on M3-004's storage. Decision: "Application state decision (M3-001)"; storage: "State storage decision (M3-004)"; the `get` half: M3-003.

- `src/muntin/app.mojo`: two adapters, `_call_state_body[S, B, E, R, respond]` and `_call_state_int_body[S, B, E, R, respond]`, each `_call_body`/`_call_int_body` with `bound.state` passed first by borrow (the spike's, unchanged in logic), and four `App.post` overloads taking `(handler, state: State[S])`:
  - `def(State[S], var B) thin raises E -> String` and `-> R: ToResponse`;
  - `def(State[S], Int, var B) thin raises E -> String` and `-> R: ToResponse`.
  `S`, `B`, `E` and `R` are inferred as in their stateless twins; each repeats its twin's route checks and messages. They are placed after the raw `post`, as the stateful `get` overloads follow the raw `get`. A registration stores the handler and one copy of the handle as M3-003's `_Bound[H, S]` in `_Erased`, with `body=True`; requests borrow it.
- The `State` guard (M3-001's "Disjointness kept", deferred by M3-003): `State` conforms to a private marker trait, `_InjectedState` (`src/muntin/state.mojo`; no requirement, no field). The four stateless body overloads assert `not conforms_to(B, _InjectedState)` after the `Int` and `Request` guards and before `FromBody` ("State is injected application state, not the request body; a stateful post handler takes State first and the body last, and the state is the registration's second argument"); the four stateful ones assert it in the body slot ("a handler takes at most one State, as its first parameter"). Like the `Request` guard, it changes only the message of calls that already fail; selection is unchanged (argument count still separates the families). It is not a dependency-injection abstraction: nothing else conforms, and nothing reads it but these asserts.
- Unchanged: `_Erased`, `_Call`, `_Route`, `_handler_storage.mojo` (`_Shared`), `check_unsafe.sh` and the unsafe surface, `State`'s fields and public API (`State(value)`, `.copy()`, `state[]`), `_Bound`, the stateful `get` overloads and adapters, `App.handle`, `http.mojo`, `body.mojo`, `testing.mojo`, `adapters/flare/muntin_flare.mojo`. `App` stays non-generic.
- Behavior: the stateless twin's. Route value first (400 without calling `from_body`), then the body (`from_body` raising is 400 without calling the handler), then the handler once and the result policy once; a raise is `ToErrorResponse` or the fixed 500; 404 without a match; first registration wins, across the stateless and stateful families. Typed routes receive no header strings (M3-005), so request fields take no part.
- Lifetime: each registration raises the handle's count by one; requests of every shape and outcome leave it unchanged, read inside handlers of both shapes; dropping the `App` releases the routes' handles; the value is dropped once across two `App` moves.
- Diagnostics: of the 178 existing must-fail fixtures (all directories, built against production), 170 are identical. The 8 that change are failing one-argument `post` calls with no viable overload (`body_fail/post_body_then_int`, `post_int_and_two_bodies`, `post_int_body_non_conforming_return`, `post_no_param`, `post_non_conforming_return`, `post_owned_int_and_body`, `post_two_bodies`, `raw_extra_parameter`): each gains the four stateful candidates' `missing required argument: 'state'` notes, the error line's caret moves from the handler argument to `post`, and four of them lose trailing detail notes to Mojo's ten-note cap (the compiler reports 3, 3, 1 and 4 omitted for `post_body_then_int`, `post_owned_int_and_body`, `post_two_bodies` and `raw_extra_parameter`; the lost notes are `result type.origin ...`, `.id of the first type ...` and `result type of the first type ...` details). Every expected text still matches. `get` diagnostics are unchanged. One message changes for a call outside the slice: a stateful raw handler `def(State[S], Request) -> Response` on `post` with its state reaches the stateful `ToResponse` body overload (`B = Request`) and gets the `Request` guard message (`state_post_fail/raw_stateful_post.mojo`, retired by M3-007, which made the shape production).
