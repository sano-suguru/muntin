Status: **production**, the M3-014 slice with one decision amendment. The decision, rejected candidates, invariants and revisit conditions are "Registration structure decision (M3-014)" above, and the fourth accepted-set edge is "Registration structure amendment: generic forwarding (M3-015)"; this section records what production does and the measured diagnostics. It reopens M2 as that record decided (the overload declarations, the diagnostics of rejected calls and three edges of the accepted set) and as the amendment added (a fourth edge).

- **Final overloads** (`src/muntin/app.mojo`), six per method, every one carrying `where (R == String or R == StaticString or conforms_to(R, ToResponse))` exactly:

  ```mojo
  def get[E: Deinitable, R: Movable & Deinitable, //, path: StaticString](mut self, handler: def() thin raises E -> R)
  def get[A: Movable & Deinitable, E: ..., R: ..., //, path: StaticString](mut self, handler: def(var A) thin raises E -> R)
  def get[A: ..., B: ..., E: ..., R: ..., //, path: StaticString](mut self, handler: def(var A, var B) thin raises E -> R)
  def get[S: Movable & Deinitable, E: ..., R: ..., //, path: StaticString](mut self, handler: def(State[S]) thin raises E -> R, state: State[S])
  def get[S: ..., A: ..., E: ..., R: ..., //, path: StaticString](mut self, handler: def(State[S], var A) thin raises E -> R, state: State[S])
  def get[S: ..., A: ..., B: ..., E: ..., R: ..., //, path: StaticString](mut self, handler: def(State[S], var A, var B) thin raises E -> R, state: State[S])
  # post: the same six signatures
  ```

  Each body is `_check[method, stateful, path, R, A, B]()` (absent slots are the private `_NoSlot`), then `comptime if _admits[...]():` around the one `self._routes.append(_route[Last](method, path, _Erased.__init__[call=<adapter>](...)))`, else `abort("registration rule check and guard disagree")`. `_route[Last]` sets `_Route.body`, `json`, `headers` and `raw` from the last slot's type.
- **Slot kinds** (`_kind[A]`): `_NoSlot` absent; `A == Int` a route value; `A == Request` raw; `conforms_to(A, _InjectedState)` a misplaced `State`; `FromBody` or `_HeaderCarrier` a body; anything else no kind (`String` and `Headers` included). Type equality is exact for these origin-free types.
- **Rules** are one ordered function per method, `_get_rule` and `_post_rule`, over the slot kinds, whether `R == Response`, and the literal's path and query placeholder counts; `_rule` adds the malformed-literal check first. It returns `_OK` or one code per message. `_check` asserts `rule != <code>` once per message, and `_admits` is `_rule(...) == _OK`. The order keeps every message the per-shape overloads gave for the same shape: `post`'s one-slot path checks the placeholders, then `Int`, then `State`, then `FromBody`, as the old body overload did, and a `Request` with a result other than `Response` is also reported after the placeholders (the old body overload's order; a raw handler returning `Response` gets the old raw overload's placeholder messages); its two-slot path reports a first slot other than `Int` before the placeholders (only shapes the old overloads did not select get there), then checks the placeholders and the body slot in the old order. Messages kept (every constraint text an existing fixture expects): `malformed route literal`, the two `route declares ... but the handler takes none`, `handler takes one Int parameter; ...`, `handler takes only the request body; ...`, `handler takes one Int parameter and the request body; ...`, `Int is a route-value type, ...`, the two `Request is the whole request, not a body; ...`, `State is injected application state, not the request body; ...`, `a handler takes at most one State, as its first parameter`, and the two `... request body; its type must conform to FromBody`. New messages, each naming the method: `a get handler takes no request body`; `a get handler takes at most one Int route value`; `a get handler's parameter is an Int route value or, for a raw handler, the Request`; `a raw get handler takes only the Request and returns Response`; `a stateful raw get handler takes State first, then only the Request, and returns Response`; `State is injected application state; a stateful get handler takes State first, and the state is the registration's second argument`; `a post handler takes the request body as its last parameter`; `a post handler takes one request body, as its last parameter`; `a post handler's parameter before the body is an Int route value`; `a raw post handler takes only the Request and returns Response`; `a stateful raw post handler takes State first, then only the Request, and returns Response`. On `get`, a second `State` reuses `post`'s existing `a handler takes at most one State, as its first parameter`. A last assert, `internal: a registration rule has no message`, fires only if a code lacks its assert.
- **Adapters and request order:** `_call_0`, `_call_1`, `_call_2` and `_call_state_0` to `_call_state_2` replace the ten hand adapters. Each converts its slots in order with `_slot[A, at]` (`raises _Reject`, a status), calls the handler alone in its `try` (`_handler_error[E]`), then `_respond[R]`. A slot's raw index is its position, because the only route value precedes the body. `_slot`: `Int` through `_parse_int` (400); `Request` through `_raw_request` (500 on failure); a body: for `_JsonBody`, `_json_status` first (415, 413), then for a carrier `_carrier_fields` (500) and `_from_parts` (400), else `from_body` (400). `_rejected` maps 400 to `_bad_request`, 500 to `_internal_error` and 415/413 through the kept `_json_answer`. `_respond`: `String` and `StaticString` are `Response.text`, anything else (`Response` included, unchanged by its own `to_response`) is `to_response()`. The order is production's: 404, query 400 (`App.handle`), route value 400, 415, 413, field rebuild 500, `from_body` 400, handler, result. `_Respond`, `_text` and `_converted` are gone; `_Route`, `App.handle`, `_json_status`, `_carrier_fields`, `_raw_request`, `_handler_error`, `_Bound`, `_Call`, `_Erased` and `_handler_storage.mojo` are unchanged except docstrings (`_Route.raw`, `App.handle`).
- **The one rebind:** `_as[T: Movable, A: Movable](var value: T) -> A` asserts `A == T` (`rebind requires generic type equality`) and returns `rebind_var[A](value^)` on the next line. `_slot` uses it for `Int` and `Request`, `_respond` for `String` and `StaticString`. `scripts/check_unsafe.sh` now also requires exactly one `rebind_var[` in `src/muntin` (storage module, comments and docstrings included), in `app.mojo` on the line after `comptime assert A == T`; fails if any other module names `rebind_var` or `std.builtin.rebind`; and requires `app.mojo`'s import to be exactly `from std.builtin.rebind import rebind_var`. The check covers `rebind_var` as decided; the prelude's reference form `rebind`, which needs no import, is not used in `src/muntin` and is not checked (a possible follow-up).
